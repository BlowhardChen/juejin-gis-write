# React Native GIS Mobile

Use this skill for:

- React Native map systems
- mobile GIS
- smart agriculture GIS apps
- mobile positioning
- offline maps
- map interaction
- sensor integration
- compass and heading
- trajectory rendering
- location tracking

## Technical Focus

Discuss:

- React Native architecture
- native bridge communication
- OpenLayers integration
- WebView map rendering
- Android/iOS GIS differences
- mobile rendering optimization
- sensor usage
- GPS accuracy
- offline capability

## Engineering Requirements

Always include:

- platform compatibility
- Android/iOS differences
- performance optimization
- permission management
- mobile interaction issues

## Important Rule

Do not write purely web-oriented GIS articles.

Must reflect:

- mobile device constraints
- mobile rendering characteristics
- cross-platform issues
- RN engineering patterns

## Preferred Structure

1. 业务场景

3. 技术方案
4. 核心实现
5. 跨平台问题
