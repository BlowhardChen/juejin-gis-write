# OpenLayers Core

Use this skill for:

- OpenLayers fundamentals
- Map initialization
- View and Projection
- TileLayer and VectorLayer
- Feature and Geometry
- Interaction and Overlay
- Event system
- Layer switching

## Teaching Style

Explain concepts progressively:

- what it is
- why it exists
- how it works internally
- engineering usage

## Preferred Article Structure

1. 功能背景
2. OpenLayers 核心概念
3. API 分析
4. 实战代码
5. 常见问题
6. 工程实践建议
7. 总结

## Important Rules

Do not only explain API usage.

Always explain:

- rendering mechanism
- layer-source relationship
- projection impact
- feature lifecycle
- event flow

## Code Requirements

- TypeScript preferred
- Vue3 examples preferred
- Avoid oversimplified examples
- Use realistic engineering structures

## Tone

Clear, professional, engineering-focused.
