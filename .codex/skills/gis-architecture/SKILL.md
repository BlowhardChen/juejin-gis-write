# GIS Architecture

Use this skill for:

- GIS platform architecture
- map middle platform
- GIS SDK design
- layer management architecture
- frontend GIS engineering systems
- micro frontend GIS
- map state management
- GIS component systems

## Writing Focus

Articles must focus on:

- scalability
- maintainability
- modularity
- engineering abstraction
- business extensibility

## Architecture Topics

Discuss:

- map engine abstraction
- layer lifecycle
- source management
- GIS service encapsulation
- coordinate system consistency
- interaction architecture
- plugin architecture
- event bus design
- map state synchronization

## Important Rule

Avoid generic architecture theory.

Always connect architecture with:

- GIS rendering
- business scenarios
- engineering implementation
- frontend limitations

## Preferred Structure

1. 业务背景
2. 架构痛点
3. 技术方案设计
4. 模块拆分
5. 核心实现
6. 架构优化
7. 工程落地经验
8. 总结

## Tone

Senior engineer / technical architect style.
