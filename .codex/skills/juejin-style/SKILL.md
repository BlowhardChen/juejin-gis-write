# Juejin Style Writer

Use this skill when generating Chinese technical articles intended for:

- 掘金
- CSDN
- 开发者社区
- 技术专栏
- 工程实践分享

## Writing Goals

The article should:

- improve readability
- increase completion rate
- reduce AI-generated feeling
- resemble real engineering sharing
- fit 掘金 technical article style

## Title Rules

Titles should:

- contain technical keywords
- contain engineering scenarios
- avoid clickbait
- avoid overly academic wording
- prefer practical problem-driven naming

Good examples:

- OpenLayers 图层管理架构设计实践
- React Native 地图定位踩坑总结
- 如何解决 OpenLayers 海量点位卡顿问题
- 企业级 GIS 地图系统如何做图层管理

Bad examples:

- OpenLayers 教程
- 地图学习笔记
- GIS 相关知识

## Paragraph Rules

- Keep paragraphs relatively short
- Avoid large blocks of text
- Prefer engineering explanation style
- Add contextual transitions naturally
- Avoid repetitive formatting patterns

## Technical Writing Style

Prefer:

- real project context
- troubleshooting process
- architecture reasoning
- engineering tradeoffs
- performance discussion

Avoid:

- official documentation tone
- API listing style
- repetitive definitions
- empty conclusions

## SEO Optimization

Naturally include:

- OpenLayers
- GIS
- 前端地图
- React Native
- 地图可视化
- 坐标系
- WMTS
- EPSG
- 图层管理
- 海量点位

Do not stuff keywords unnaturally.

## Article Rhythm

Recommended rhythm:

1. 背景问题
2. 为什么会出现
3. 底层分析
4. 解决方案
5. 工程优化
6. 总结经验

## Code Display Rules

Code examples should:

- appear in meaningful sections
- not be excessively fragmented
- include engineering comments
- resemble production code

## Reader Experience

Readers should feel:

- “这是实际项目经验”
- “作者真的做过GIS项目”
- “不是AI拼凑的教程”

## Tone

Professional, practical, engineering-oriented.
