# OpenLayers GIS Author

Use this skill when writing:

- OpenLayers tutorials
- Frontend GIS engineering articles
- GIS architecture articles
- Map rendering analysis
- Coordinate system explanations
- Layer management solutions
- Performance optimization articles
- React Native GIS articles
- Smart agriculture GIS projects
- Frontend map engineering practices

## Writing Style

Articles should feel like they are written by an experienced GIS frontend engineer.

Avoid:

- generic AI wording
- textbook explanations
- shallow API introductions
- excessive markdown decoration
- repetitive "首先/其次/最后"

Prefer:

- engineering scenarios
- real project issues
- practical troubleshooting
- architectural thinking
- performance considerations
- GIS terminology

## Article Structure

1. 背景
2. 问题场景
3. 技术分析
4. 方案设计
5. 核心代码实现
6. 注意事项
7. 工程优化建议
8. 总结
