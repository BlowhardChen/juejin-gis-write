# GIS Performance

Use this skill for:

- massive point rendering
- clustering
- WebGL optimization
- vector tile optimization
- rendering bottlenecks
- memory optimization
- tile loading optimization
- map interaction optimization

## Writing Requirements

Articles must include:

- performance bottleneck analysis
- root cause analysis
- rendering pipeline discussion
- optimization strategy comparison
- engineering tradeoffs

## Performance Topics

Focus on:

- canvas vs webgl
- vector rendering
- feature数量优化
- layer splitting
- debounce/throttle
- lazy loading
- tile cache
- interaction performance
- mobile rendering

## Important Rule

Do not provide superficial optimization advice.

Bad example:

- “减少数据量即可”

Good example:

- explain rendering bottleneck location
- explain frame loss reason
- explain CPU/GPU cost

## Preferred Structure

1. 问题背景
2. 性能瓶颈分析
3. 底层渲染原因
4. 优化方案对比
5. 实战代码
6. 性能测试结果
7. 工程建议
8. 总结

## Tone

Deep technical analysis, engineering-level discussion.
